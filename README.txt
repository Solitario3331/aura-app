AURA - how to install (once)

1. Download this folder (GitHub: green Code button > Download ZIP) and unzip it anywhere, for example Documents.
2. Double-click install.bat and answer the two questions.
   - You need your own Claude account (the installer opens the sign-in).
   - If the free helper runs on Amar's PC: his PC must be on with Ollama running.
3. Open "Aura" from your desktop (or Start menu).

Updates: Settings > Update, then close Aura and open it again.
Problems: double-click check_setup.bat and send the result to Amar.
