AURA - how to install (once)

1. Download this folder (GitHub: green Code button > Download ZIP) and unzip it anywhere, for example Documents.
   Windows may warn that the files came from the internet: click "More info" > "Run anyway".

2. Double-click the right installer:

   * Install-Colleague.bat   <- if YOUR OWN PC has the big graphics card (for example an RTX 5090).
     It installs everything for you: the free helper (Qwen) runs on YOUR PC, the professional look,
     and an Aura icon on your desktop. It downloads the helper model once (about 17 GB, this takes a while).
     If it asks you to close the window and run it again, just double-click it again.

   * install.bat             <- everyone else. It asks two questions (where the free helper runs, which look).
     If the free helper runs on Amar's PC: his PC must be on with Ollama running.

   You need your own Claude account: the installer opens the Claude sign-in (log in, then type /exit).

3. Open "Aura" from your desktop (or the Start menu).

Updates come from Amar: Settings > Update (a small pop-up at the top also tells you when there is one).
Press it, then close Aura and open it again.

Problems: double-click check_setup.bat and send the result to Amar.
